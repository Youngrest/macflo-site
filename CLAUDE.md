# MAC.FLO — демо-сайт цветочной студии

Полная передача проекта: **HANDOFF.md** — читать первым. Продажа/цены/апселлы: SALES.md (приватный, не в git).

## Правила
- Дизайн утверждён заказчиком. Менять только то, что попросили, точечно. Не переделывать палитру, шрифты, hero-эффект, порядок секций.
- Не возвращать убранное: кружки-сторис, плашку «до 20:00», цены на макаруны, карточки без фото, вкладки.
- Токен бота — только в `site/secrets.js` (гитигнор) и в секретах GitHub. Никогда в `config.js`/`index.html`/`app.js`.
- Товары и цены — только в `site/config.js`.
- Фото — через `photos/` + `prepare-photos.ps1`, не класть оригиналы в `site/img/`.
- Стек: статика сейчас, PHP + MySQL на REG.RU потом. Не предлагать Node/React/Docker/VPS.
- Контакты (телефон, адрес, график, TG) реальные — не менять без просьбы.
- После правок CSS проверять мобильную версию.
- `git push` — только когда попросили. Деплой на Pages происходит автоматически при push в `main`.

## Локально
`powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:8765/ (Python/Node на машине нет).
